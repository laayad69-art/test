# Madinah Mushaf Viewer

A single-file HTML app that displays all 604 pages of the Madinah Mushaf,
lets you select pages, and download the selection as a ZIP.

## Folder structure

```
mushaf-app/
├── index.html          # the whole app (HTML + CSS + JS, no frameworks)
├── download_pages.py    # one-time script to fetch the 604 page images
├── README.md
└── pages/               # created by download_pages.py
    ├── page001.png
    ├── page002.png
    ├── ...
    └── page604.png
```

`index.html` never talks to the internet for the Mushaf images themselves —
it only loads `./pages/pageNNN.png`, so there are no CORS issues. It does
load the JSZip library from a CDN (`cdnjs.cloudflare.com`) to build the ZIP
file in the browser; if you need a fully offline setup, download
`jszip.min.js` once and change the `<script src="...">` tag in `index.html`
to point at a local copy.

## 1. Download the page images (one time)

```bash
cd mushaf-app
pip install requests   # not strictly required — the script uses only the
                        # standard library, but requests-based mirrors are
                        # common if you swap the source later
python download_pages.py
```

This downloads all 604 pages into `./pages/` as `page001.png` … `page604.png`.
It's resumable — if it's interrupted or a few pages fail (network hiccup),
just run it again; already-downloaded pages are skipped automatically.

Useful flags:

```bash
python download_pages.py --start 1 --end 50     # only pages 1–50
python download_pages.py --workers 10             # more parallel downloads
python download_pages.py --out ./pages            # custom output folder
```

## 2. Open the app

Because the page loads local images via `fetch`/`<img>`, serve it over
`http://` rather than opening the file directly with `file://` in some
browsers (Chrome in particular can block local `fetch()` calls under
`file://`). The simplest way:

```bash
cd mushaf-app
python -m http.server 8000
```

Then open **http://localhost:8000/** in your browser.

(Double‑clicking `index.html` to open it directly may also work for
viewing thumbnails, but use the local server method above if the
"Download Selected" ZIP button doesn't work.)

## Using the app

- **Search** — type a page number in the search box to filter the grid.
- **Click a thumbnail or its checkbox** — both select/deselect that page.
- **Select All / Unselect All** — apply to the currently visible (filtered) pages.
- **Download Selected** — fetches the selected page images and bundles them
  into `madinah-mushaf-pages.zip`, with a live progress bar. Failed/missing
  pages are reported after the fact instead of stopping the whole download.

## Source of the images

`download_pages.py` pulls from the `tarekeldeeb/madina_images` GitHub
repository (page scans generated by the `quran/quran.com-images` project
using King Fahd Quran Complex fonts), served via GitHub's raw content CDN
(`raw.githubusercontent.com`), with a `cdn.jsdelivr.net` GitHub mirror as an
automatic fallback if the primary URL fails for a given page. Both hosts
send permissive CORS headers, so this works cleanly from a local page —
unlike hosts such as quran.islam-db.com, which block cross-origin requests.

If you'd rather use your own scans, just drop your own PNGs into `pages/`
named `page001.png` … `page604.png` — `index.html` doesn't care where they
came from.
